# Employee-Attrition-Analysis
Employee Attrition Analysis using Python and Tableau
Employee Attrition Analysis

Project Overview

An exploratory data analysis project focused on understanding employee attrition and identifying workplace factors associated with employee turnover.

This project uses Python for data cleaning and analysis and Tableau for data visualization.

Objectives

- Analyze employee attrition patterns.
- Explore employee demographics and job-related factors.
- Identify trends and factors associated with employee turnover.
- Present insights through interactive visualizations.

Tools & Technologies

- Python – Data analysis
- Pandas & NumPy – Data manipulation
- Jupyter Notebook – Analysis environment
- Tableau – Data visualization
- GitHub – Project documentation and version control
